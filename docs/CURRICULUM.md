## 2. Course-level curriculum logic

The original sequence matches a conventional ML journey:

- conceptual foundations
- data pipeline and preprocessing
- feature quality and dimensionality reduction
- linear models and optimization
- classification theory and evaluation
- probabilistic models and kernel methods
- trees and ensemble methods

This is a strong, teachable progression and provides the backbone for the final ML Atlas guide.
